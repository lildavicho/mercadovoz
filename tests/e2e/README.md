# E2E

El flujo crítico se valida contra una aplicación local o un entorno privado:

1. aceptar consentimiento;
2. enviar una venta;
3. ver la confirmación;
4. corregir un campo;
5. confirmar;
6. comprobar historial y auditoría;
7. repetir confirmación y verificar que no se duplica.

No usar datos reales en CI. La evidencia manual de Sprint 3 está en `docs/pilot/SPRINT_3_REPORT.md`.
